# 图像生产判断

仅在相应问题出现时读取，以当前 create-pet 技能及脚本为权威。

## 身份和布局

- canonical 只含一个完整角色；原参考是三视图时明确只参考身份/服装，不复制三视图布局。后续行带 canonical 与所有身份参考。
- 正常比例人物在格子里脸较小，仍保持用户所选比例。紧凑处理附肢姿态、取景、细节密度，不改成大头 Q 版。影响身份的造型变化先展示具体方案。
- 每个姿势保留完整角、头发、翼、尾、衣摆和鞋。相邻姿势留纯背景间隔；宽翼、长尾、长裙特别容易相接。
- 内容正确但太挤时，可用 imagegen 编辑完整状态条带，让各人物分别在各自槽内缩小、增大间隔并保留动作。只把整个条带连背景一起缩小不会解除人物重叠。
- 不等距条带不能按假定等宽槽切穿角色。优先用官方完整连接组件/姿势组提取；可把提取出的四主方向规范排列，再调用官方锚点验证。脚本 ok 不能替代目视完整性。

## 动作和缩放

- 待机有可见微动；工作状态是思考/处理；检查与思考、等输入有区别。不为区分状态添加原身份没有的道具或浮动图标。
- 左右跑先检查饰物、光照、持物、开衩的非对称性；镜像改变身份就独立生成。允许镜像时逐帧镜像，保留时间顺序。
- 跳跃使整个接地部分离地再返回；长裙/尾巴一直拖在基线上不算合格跳跃。
- 逐帧紧裁拉满会抹掉跳跃或产生大小弹跳。保留同组比例和源位移；出现跨状态身高跳变再统一登记整行。别放大到角/翼尖越界。
- 先判断源画错误还是提取/缩放错误；确定性问题用确定性修复，源画确错才重新生成。保留通过的行和有用修订。

## 方向和环视

- 四主方向是屏幕上、右、下、左。先通过鼻尖、下巴、虹膜/眼睑或角色自身瞄准特征建立锚点，再顺时针做两组连贯八姿势。
- 人形通常下半身、接地点、尾根、翼根固定；眼和头自然转向，耳/角/刘海跟头，不把整人转成背面展示转台。
- 第一半圈完成源图和注册格检查后才生成第二半圈。第二半圈匹配第一半圈源人物高度与基线，复用同一变换，检查两组接缝。
- 近竖直方向水平分量可能小。主方向错、象限错、顺序反转、脸消失、明显跳变必须修；中间相似只能在原生尺寸与完整顺序检查后记录 warning。盲评主方向分歧不能凭“连续性指标很好”跳过。
- 超出参考图数量上限时，合并静态身份参考；布局引导、已批准方向/上一半圈保留独立输入并解释用途，不静默丢参考。

## 编码与完成状态

- 最终字节执行一次最终溢色清理，再跑官方门禁。源图/编码变化后重建受影响预览并重跑，不给新文件沿用旧报告。
- 在浅/深背景及原生尺寸检查边缘、连接、意外透明洞。依据可见性记录轻微色晕；明显绿边不能因几何通过而忽略。
- 运动预览来自最终文件，不用主形象截图冒充动画；展示运动后再上传。图集不是能双击运行的程序。
- 分清材料已生成、MCP 已验证、stable ID 已创建、active 已选中、浮层已显示；没有工具时交付能完成的材料并说明缺口，不制造假的安装成功。
